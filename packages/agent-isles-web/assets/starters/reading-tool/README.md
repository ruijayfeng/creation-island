# Creation Island starter / 创作岛内置起点

Serve this folder with a local HTTP static server. No install, account, model or network required.
使用 HTTP 静态服务运行本目录，无需安装、账号、模型或联网。

Browser data stays in the preview origin and is not copied with source files.
浏览器记录不会随源码复制；预览地址变化可能显示新的存储。

Original HTML, CSS and Canvas artwork created for Creation Island. MIT; see LICENSE.
代码与程序几何为创作岛制作，无外部字体、图像或接口。
