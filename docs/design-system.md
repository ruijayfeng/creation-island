# 海岛创作工坊：界面优化约定

2026-10-08。沿用三类作品与本地交付范围。本轮将已有创作能力整理为以作品为中心的工作台，参照 oil-ui 的设计方向比较与真实界面检查方法，不引入其运行脚本或新依赖。

## 全局语言

- 品牌层：已有小岛与伙伴出现在首页、欢迎与创作辅助入口。
- 操作层：暖白 #F7F6F2、白色内容纸面、深绿 #22675B 主操作、正文 #24352F；正文与输入 14–16px，辅助信息 12–13px；间距 4/8/12/16/24/32。
- 作品层：清新、庆祝、夜色沿用同一个播放器，作品主题不改变工具界面。封面展示真实标题与内容片段。
- 状态层：选中、焦点、保存中、失败、待采用分别明确呈现；不凭点击显示成功。尊重减少动效设置。

## 核心流程

1. 首页优先展示继续创作与近期作品；样例入口始终可见，三维探索可选。
2. 工作台左侧为作品目录；中间明确切换编辑/试玩；AI 伙伴可按需打开。编辑一次聚焦一个对象，作品设置集中放置。
3. 目录选择同步 AI 修改范围；用户可显式切回整个作品。故事目录显示起点、结局与连线去向，支持点击目标定位。
4. AI 候选在中央审核，显示真实前后文字变化、采用/放弃和候选试玩入口。候选不自动覆盖草稿。
5. 导出遇到草稿差异时，明确提供保存新版本后导出、导出上次保存版本、返回编辑。取消不执行导出。
6. 窄窗口切换目录、编辑/试玩、伙伴；主操作保留，次要操作收进菜单。所有文案中英同步。

## 阶段保存与集中验证

1. 设计约定与规格同步。
2. 工作台、对象目录、差异审核、导出选择。
3. 首页、作品封面、全局样式及响应布局。
4. 统一构建与必要回归，真实界面检查：三类对象编辑、AI 范围、版本与导出、中英、宽窄窗口、键盘与模态。

只在实际执行后登记验收。已有模型质量数据不作为新 UI 效率提升的证据；本轮不承诺未经测量的效率百分比。
