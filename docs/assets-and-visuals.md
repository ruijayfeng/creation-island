# 视觉与素材方案

## 视觉方向

产品采用温暖、轻松、有秩序的创作空间。三维世界沿用低多边形基础，编辑界面以清晰排版和轻量卡片呈现，重要操作使用统一强调色。伙伴提供情绪和引导，编辑区保留足够空间，避免角色装饰压住作品内容。

品牌文字暂定“创作岛”，英文为 Creation Island，统一从品牌配置读取。应用图标使用岛屿与创作光点的简单组合，不把整张场景图缩小成图标。先完成可编辑 SVG，再输出发行所需尺寸。

默认界面采用暖白底、深色正文、青绿色主操作和少量琥珀色提示。起始色值为背景 `#F7F6F2`、面板 `#FFFFFF`、正文 `#24352F`、主色 `#22675B`；它们是设计起点，统一测试时检查实际对比度及焦点显示。

清新、庆祝、夜色三套作品主题共用组件尺寸和交互逻辑，分别调整颜色、内置图形和动效。主题切换不改内容和业务规则。

## 素材选择顺序

先复用基线中有来源记录的世界和角色资源；图标、卡面、状态及简单动效优先使用程序绘制；需要丰富图像时使用内置生图工具；缺少特定资源时从明确来源的素材站或开源项目获取。

素材到具体页面和展示尺寸确定后再制作。开发早期用同尺寸占位，避免提前生成大量最终不会使用的图片。运行时和导出文件不依赖在线素材 CDN。

## 需要交付的素材

| 素材 | 制作方式 | 输出与使用 |
| --- | --- | --- |
| 应用图标与字标 | 原创 SVG；必要时生图探索后重新绘制 | SVG 源、1024 方形 PNG、打包所需图标尺寸 |
| 欢迎插画 | 内置生图，参考实际小岛和统一色调 | 16 比 9 构图，WebP；文字与按钮由界面绘制 |
| 伙伴头像 | 先复用可复用角色并统一裁切，后续需要时制作衍生图 | 512 方形透明 PNG 或 WebP，圆形裁切不丢主体 |
| 三类作品封面 | SVG 或 Canvas 程序绘制 | 问答、贺卡、分支故事各一套符号与卡面，随标题及主题变化 |
| 作品主题装饰 | SVG、CSS、少量 Canvas | 清新叶片、庆祝纸片、夜色星点；不嵌入不可编辑正文 |
| 六个展示位 | 基于原世界制作低多边形展台或展牌 | 可重复使用的 Godot 场景和碰撞区域；点击后打开应用面板 |
| 常用操作图标 | 优先复用现有图标体系，需补充时用 Lucide | 相同线宽、尺寸及焦点样式；保留适用声明 |
| 空状态插画 | SVG 或内置生图 | 无作品、搜索无结果、生成失败三种；文案独立绘制 |
| 完成动效 | 首选 CSS 和轻量 Canvas，复杂需求再用库 | 可关闭、有限持续时间，不阻止继续操作 |
| 字体 | 世界固定 UI 沿用已有字体；编辑器与导出用系统字体栈 | 不要求用户安装字体，不依赖网络字体 |

世界原字体是有限字符子集，不能假设覆盖用户任意中文输入。创作内容使用系统字体回退；如未来需要嵌入完整或新增子集字体，单独记录来源和随包许可。

## 生图制作说明

需要生成栅格图像时，使用内置 imagegen 工具，遵循其技能与工具要求。已有本地参考图先查看，再传入编辑或生成流程。首选复用一张确认风格的参考图来保持色调和角色一致。

欢迎图制作要求：柔和低多边形岛屿、自然地面、小型创作工作台、暖光、少量生活道具，留出可放界面内容的空间；画面中不生成标题、按钮或假 UI。图内物体与实际产品相符。

空状态图制作要求：使用同一角色和光照，分别表达等待创作、寻找作品和遇到小障碍；透明背景、主体完整、少量道具、无文字。失败状态保留轻松但清晰的情绪，不表现成作品已经成功。

生成后检查边缘、伪文字、角色一致性和实际显示效果，裁切和压缩后登记。生成图只用于视觉资源，题目、祝福和故事文本由可编辑内容系统负责。

## 程序制作与第三方库

卡面由标题、类型符号和主题 token 生成，同一方法供收藏与岛上展示使用。小尺寸 SVG 优先；动效在元素退出、关闭预览和减少动态效果设置开启时停止。

第三方 JS 先检查项目已有依赖是否满足需求。确需引入时固定版本，正常写入依赖与锁文件。导出 HTML 使用本地打包后的必要代码和适用声明，不从 CDN 加载库，也不把完整应用运行时装进每份作品。

三维展示位使用简单几何体或沿用有来源的现成模型，先保持原世界的比例、光照和碰撞方式；不为本次产品重做整张地图。

## 文件组织与登记

源素材进入相应模块的 `art/` 或 `assets/source/`；运行资源进入该模块打包实际使用的目录；许可和来源与模块资产一起保留。具体目录在导入基线后按现有构建入口映射，避免另建未被打包的公共资源树。

`asset-register.csv` 一行对应一项实际资源或明确来源集合。未采用的候选标为候选，已核对但未导入的基线资源标为待导入；采用后补齐本地路径、许可文本位置和 SHA-256。生成素材记录工具、生成日期、提示词记录位置及后续编辑，许可字段注明生成来源，不自行标为 CC0。

## 素材收尾检查

在统一测试阶段集中检查：实际尺寸下清晰、角色及主题一致、长标题不遮挡、三套主题文字可读、动效可关闭、断网资源完整、发行包声明齐全。占位素材全部替换或明确作为设计保留，不把素材未完成隐藏在功能已完成状态中。

## 内置样例内容

- 问答：露营装备小问答，五道题，题目和答案人工确认，展示答题解释与结束页。
- 贺卡：给朋友的一次生日祝福，打开信封、逐段揭晓三段祝福、结束庆祝，可再次播放。
- 故事：在小岛寻找一颗失落的星星，以三个选择节点和至少两个结局展示真实分支；图中所有节点可达且无循环。

样例用于展示可实现能力。用户点击制作自己的版本后创建新作品，不修改内置样例，也不将样例自动算作用户已完成作品。
