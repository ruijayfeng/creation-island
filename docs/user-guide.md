# 创作岛使用说明

创作岛在 macOS Apple Silicon 上运行。解压发行包后，保持整个文件夹完整，双击 `Creation Island.app`；菜单栏的 ◒ 可重新打开界面或退出服务。当前为未公证的开发候选包，首次启动可能需要在系统设置中允许打开。

## 制作第一份作品

1. 在灵感手册试玩问答、贺卡或分支故事，点击“制作我的版本”。
2. 从左侧作品目录选择设置、题目、段落或故事节点，一次编辑一处；草稿自动保存。中间的“编辑 / 试玩”切换用于修改和实际体验。
3. 需要 AI 时，在“模型设置”配置自己的服务商、模型和密钥，并测试连接。调用费用由模型服务商收取。
4. 打开“创作伙伴”，告诉伙伴作品给谁、表达什么。目录选中的题目、段落或节点同步为修改范围，也可选择整个作品。候选返回后查看改前/改后内容，试玩后选择采用或放弃。
5. 点击“保存版本”形成可恢复的记录。岛上展示位只展示已保存版本。
6. “导出可玩文件”生成独立 HTML，接收者用电脑浏览器离线打开即可玩；“更多操作 → 备份可编辑作品”生成作品包，可在收藏中导入继续修改。

草稿缺少答案、故事存在断路等情况会显示校验提示，保留上一次有效预览。补齐后才能保存版本和导出。AI 生成的事实内容需要作者确认。

导出时若草稿有新修改，选择“保存新版本并导出”或“导出上次保存版本”；“返回编辑”和 Esc 都不会导出。导出完成提示中显示实际版本时间。

窄窗口使用“作品目录 / 内容与样式 / 创作伙伴”切换区域；故事目录的路线可直接跳到目标节点。

## 保存与恢复

作品、模型设置与日志位于 `~/Library/Application Support/Creation Island/data`。导出文件位于其 `exports` 子目录，可从导出提示“在访达中显示”。请勿在应用运行时手动编辑内部数据文件。备份作品使用产品内的作品包导出。

历史版本的“从此版本继续”创建当前草稿，不删除已有版本。删除先进入回收站，可还原；永久删除无法恢复。关闭应用会中断生成，不会在重启后自动再次调用模型。生成期间编辑内容会使原候选失效。

岛屿加载慢或失败时，固定导航仍可打开作品与创作室；“轻量视图”可关闭三维背景。减弱动态效果遵循系统偏好，作品播放器也提供关闭动效选项。

## 当前边界

支持三种规定的互动作品及三套主题，不提供任意代码生成、云端分享链接、账户同步或多人社区。公开仓库中的文档区分已实现与已验收；具体测试范围见开发进度和验收记录。

运行时最低要求 macOS 13.5，实际本机验收环境为 macOS 26.5.1 / Apple Silicon；其他系统版本尚未实测。
