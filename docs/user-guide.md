# 创作岛使用说明

创作岛 0.2.0 在 macOS Apple Silicon 上运行。解压后保持整个文件夹完整，双击 `Creation Island.app`。菜单栏图标可重新打开或退出服务。候选包未作 Apple 开发者签名、公证。

## 从小岛制作项目

1. 点击阿启或下方“阿启 · 开始创作”。填写项目名和想法，创建独立项目，再发送需求。已有项目可由拾页打开文件夹或填写绝对路径；打开不会安装依赖或执行命令。
2. 使用模型设置配置自己的服务商。原生输入框支持附件、模型和权限；默认新会话采用工作区内修改与按需审批。已有会话保留原权限，请查看实际显示。
3. 阿启修改真实文件。需要授权时查看具体命令和范围，再允许或拒绝。收起、返回、专注模式只改变布局，不停止任务；“停止本轮”才取消。首版同时只执行一轮，不接受跨项目排队。
4. “看看作品”列出宿主检测到的静态目录或 Node 脚本。确认命令后启动，只有实际 HTTP 检查通过才显示可访问。可访问不代表功能正确，请实际操作；预览下方可继续在同一会话提出修改。
5. 阿渡展示真实文件与本轮差异。确认满意后“保存成果”，填写名称和运行条件，再选择六个展示位之一。任务结束不会自动保存。
6. 在成果版本中查看文件清单和排除项，导出源码；构建成功后可导出静态包。只有通过保守自包含检查的单文件 HTML 才提供单文件导出。

## 历史与交付

成果是不可变快照，历史试玩从该版本的独立副本运行。恢复创建新的项目文件夹，保留原项目、Git 历史和未提交内容。打开旧会话、切换项目和重启不会自动发请求；中断的任务需要明确继续。

源码包包含 `project/`、哈希清单和运行说明，不含 Git 历史、依赖缓存、已识别的凭据与符号链接。大于 64 MiB 的单文件、超过 1 GiB 或 50,000 个条目的项目停止保存，需先整理项目。排除清单不能保证识别所有个人内容，交付前请核对。

Node 预览脚本和“安装依赖并构建”是在本机执行的明确授权操作，请核对项目脚本。构建在独立成果副本运行。其他技术栈需要相应环境；不提供默认公网部署。浏览器下载由浏览器保存；内部数据默认在 `~/Library/Application Support/Creation Island/data`。

预览采用与宿主不同的本地来源，项目页面无法访问宿主世界桥或宿主 Cookie。预览浏览器存储属于该预览来源；不要将其当作可靠持久备份。启动新的预览会更换端口，浏览器内数据可能不再出现在新来源。

## 入口与兼容

点击角色、快捷按钮或走近互动打开同一面板，无需等待走路或剧情。Esc 收起面板，键盘可访问常用操作；窄窗口使用覆盖面板。“?” 中可开启轻量模式和减少动态效果，世界加载失败时快捷入口仍可工作。

“旧版互动作品”保留原问答、贺卡、分支故事的数据与原导出协议。原作品不会自动转换成文件项目。高级工作台是可选辅助入口。

内置 Node/npm 和固定运行时可启动应用及静态项目；框架依赖、模型账号、系统工具按项目实际需要准备。最低运行时要求 macOS 13.5；本机验收环境及跨设备限制见开放项目验收记录。
