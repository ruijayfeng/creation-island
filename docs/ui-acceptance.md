## 实际执行

- Web TypeScript 与构建通过。原有产品 20 项回归通过；新增差异语义 3 项通过：仅答案变化、稳定段落 ID 的移动/删除、故事只改路线。
- 实际 UI：1280×800 桌面、390×844 英文、319×760 中文。确认三类目录只展开选中对象，故事路线可定位，窄屏目录/内容/伙伴切换有效；目录切换回到顶部，新增节点自动定位编辑区。
- 真实模型：本轮问答第三题与贺卡第二段各一次局部修改。候选审核只列实际改动对象，可采用；范围外内容保留。贺卡采用后状态为“已采用，已更新草稿”，进入试玩可正常打开卡片。
- 第一次问答检查复用了尚未重启的旧服务，采用后状态仍显示旧版取消。更新服务后贺卡场景复验通过。未将两次观察扩展为语义正确率或效率百分比。

- 导出：有差异时打开明确选择；“返回编辑”关闭且无导出提示；“导出上次保存版本”得到旧标题文件；“保存新版本并导出”得到新标题与新版本时间。未重新执行另一电脑离线验收。
- 可访问性：模态初始焦点落在选择按钮；原 Harness 界面祖先保持 inert。原有模态焦点逻辑复用。尚未覆盖屏幕阅读器完整朗读。
