日期：2026-10-08。范围：macOS 26.5.1 / Apple Silicon，本地服务 + 浏览器界面；当前是开发候选版。此记录只描述创作岛实际执行的检查，不沿用上游项目结论。

## 自动检查

- 新产品测试：`node --test scripts/test-creation.mjs`，20/20 通过。
- 覆盖：六个中英文样例、故事循环/不可达/坏引用、问答答案引用、HTML 转义、不完整草稿、幂等请求、版本不可变与 revision 冲突、重启中断、损坏存储保留、回收站、导入新 ID、局部修改范围、中文序号解析、一次修复、澄清、取消后迟到结果、磁盘失败、采用/放弃状态、HTTP 来源边界和导出再导入。
- Web 编译与世界导出通过。品牌、消息桥、模型设置与启动监督等相关检查共 22 项：首跑 21 项通过，一项因预期仍为旧品牌失败；修正预期后消息桥 8 项复验全部通过。与新产品测试合计 42 项最终通过。
- 对 UI 文案和样式未增加机械快照测试。

## 真实模型

使用用户在应用中配置的模型；凭据不读取到报告、作品和仓库。三种作品 × 明确需求/澄清后生成/局部修改 × 两次，共 18 个场景，24 个产品任务。

| 检查 | 结果 |
| --- | --- |
| 合法内容结构、引用与范围 | 18/18 通过 |
| 只修改指定对象 | 6/6 保留范围外字段 |
| 候选采用、保存版本、HTML 导出 | 18/18 完成 |
| 场景耗时 | 3–20 秒，含轮询与部分场景的澄清；不是单次模型延迟 |
| 实际供应商请求次数、Token 与费用 | 此轮没有逐调用计量，无法确认；不能把 24 个任务当作供应商调用总数 |

初版验收脚本使用 JSON 文本比较，因对象键顺序不同，把 4 个局部修改误报为越界。已改为深度结构比较，并复核原候选、采用保存；未重新发起模型调用掩盖误报。原始记录与更正记录均留在本地 artifacts/acceptance。测试开始前一次本地服务未启动的尝试已独立归档，不计为模型失败。

人工逐份审阅了 18 份结果：贺卡满足对象、署名及段数要求；问答答案与解释可读，故事均有可达的不同结局。但结构合格不等于内容完美：一份露营回答出现“清理排水沟”，需作者结合营地规则核对；一份故事从“山谷”直接到“窗台”，过渡不足。保留原输出作为质量问题，不写成 100% 内容正确或线上成功率。应用保留采用前复核、手动编辑和再次局部修改入口。

## 浏览器实际试玩

- 问答：真实生成的植物问答走完三题、解释、计分（100 分）及重播入口。
- 贺卡：真实生成的生日卡走完打开、三段祝福、结束语、署名及再次打开入口。
- 故事：真实生成的“星星归途”分别走到天空与海上结局，中间重开成功。
- 版本：修改标题并保存，恢复旧版本后原内容出现，较新历史仍保留，再保存成功。
- 导出：界面完成 HTML 与 `.isle.json` 生成，显示本地保存位置及下载入口；接口测试导入包后为新作品且内容相同。
- 展示：收藏筛选、展示试玩、从展示直接编辑；模态打开时背景从可访问树排除、初始焦点在关闭按钮。
- 语言：中文与英文切换，按钮及播放器语言更新，作者内容保留原语言。
- 1280×720 实际查看主页和三栏创作室；三维世界可加载。窄窗口覆盖未生效，不能记为已验证。

## 未验收与已知限制

- 另一台无开发环境 Mac 的首次运行，及另一台电脑断网打开 HTML，尚未执行。当前自动化浏览器拒绝 file URL，未绕过该限制，应用内播放器检查不等于独立文件检查。
- 未完成 Apple 开发者签名与公证；不能宣称免系统拦截安装。
- 浏览器实际窄窗口布局仍需人工核验；三维展示位和角色未逐一现场走查。
- 模型费用由所配置服务商计费；生成内容需作者确认，局部语义质量不由结构校验保证。
- 当前使用本地 JSON 存储，适合个人作品规模；大量版本与长期任务历史的性能尚未压测。
- Windows、Intel Mac、移动创作端、云端同步与公网作品发布不在本轮范围。
